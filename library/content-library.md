## التنسيق

كائن JSON: `meta`, `cats`، و `cards`. كل بطاقة واجبة الحقول التالية:

| الحقل | نوع | معنى |
|---|---|---|
| `id` | سلسلة | معرّف فريد داخل المكتبة (مثلاً `g-01`) |
| `cat` | سلسلة | من 10 فئات — يكون الاختلاف بدون تداخل |
| `type` | `word` | كلمة، `sentence` | جملة |
| `level` | `easy` / `medium` / `hard` | مستوى اللغة |
| `front` | صينية | الصينية نفسها (علامات النغمة في `py`) |
| `py` | سلسلة | البينيين مع علامات النغمات |
| `ar` | عربية | الترجمة العربية المباشرة |
| `label` | `street` / `academic` / `neutral` | **المصدر والاستخدام** — يظهر للمستخدم |
| `sub` | سلسلة | مصطلح فرubic (تحية/سعر/اتجاه/... ) |
| `note` | سلسلة | شرح الاستخدام يساعد المتعلم بالطريقة الصحيحة |
| `ex` / `exPy` / `exAr` | سلسلة | جملة مُثيل (جمل فقط) — فائدة للمراجعة |
| `pair` | سلسلة | معرّف بطاقة **مثل هذه المعنى** من سطر آخر (شارعي/أكادائي) |

> الجمل المتطابقة المعنى (مثال: `你好` و `您好`) تبقى داخل العمل نفسه، وتظهر كـ **مطابقة** في البطاقة — بحيث لا يختلط الشكل والوظيفة.

## المأخذ (labels)

| `label` | ما يقال للمستخدم |
|---|---|---|
| `street` | **شارعي / عامي** — لك في الشارع، والمتجر، والهاتف، والمحادثة القريبة |
| `academic` | **رسمي / أكاديمي** — للعمل، المدرسة، الخطاب المهذب، والكتابة |
| `neutral` | **محايد** — لكل مكان |

## كيف تضيف / تُعدّل

1. عدّل `library/content-data.json` فقط (مثلاً أصنع بطاقة جديدة وتضع `cat` واحدة و`label` واضحة).
2. شغّل `python tools/build.py` — يُولّد `daily-data.js` ويطلق رسائلاً عن أي سوء توافق (تكرار في الاسم، زوج غير متبادلة، كلام غير صيني، أصوات بلا معنى).
3. أعدّ تشغيل الموقع ومُشغّل الصوت (edge-tts 7.3.1 أو Google TTS).
